\# Лабораторная работа №2: Сбор данных об уязвимостях



\## Тема



Сбор и обработка информации об уязвимостях программного продукта \*\*Suricata\*\*.



В качестве источника данных используется официальный сайт Suricata/OISF, на котором публикуются новости о релизах и закрытых уязвимостях.



\## Цель работы



Освоить базовые навыки сбора информации об уязвимостях с web-страниц и API-эндпоинтов, а также работу с форматами JSON и XML.



\## Что делает проект



Проект состоит из трёх задач:



1\. Сбор CVE с сайта поставщика ПО.

2\. Обогащение CVE через MITRE/CVE API.

3\. Конвертация итогового JSON-файла в XML.
